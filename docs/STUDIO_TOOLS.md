# 健檢、手機影片、生成配方與儲存管理

## 模型與工作流健檢

桌面左側「健檢與儲存管理」檢查六種現有模式的必要模型、執行環境與工作流。沿用生成程式的模型清單及圖結構；ComfyUI 正在執行時，另透過原生 `/object_info` 核對節點與選項，並顯示版本、可用 RAM 及顯存。服務未啟動時只檢查檔案，不會為健檢啟動 GPU 或下載模型。缺少依賴時提供既有安裝指令或說明文件。

提交真實生成任務前，後端會按本次模式、H3 配方及圖片輸入檢查必要檔案；不齊全時拒絕排隊。健檢不逐一計算數十 GB 模型的雜湊，也不保證任意解析度和片長都能在當下記憶體中完成。

## 手機 H3 圖片生影片

手機工作流新增「H3 圖片生影片」，沿用桌面的 API 與單一 GPU 佇列：

- 一次選 1～4 張首幀，每張各生成一支影片。
- 「生成參數」可調整 Turbo4、Turbo8、原版、尺寸、秒數、種子、採樣器、Shift、聲音、壓縮、縮放、裁切、主體描述與 RefMod。
- 尾幀可不使用、各自以首幀作尾幀，或另外選一張共用尾幀；尾幀不占四張首幀上限。
- H3 不傳送負面提示詞或圖片精準模式。原有手機圖片參數仍保留。
- 可查看逐支結果、取消任務、播放及下載影片。SVI 配方仍由桌面操作。

## 任務進度與時間預估

桌面生成卡片、共用任務與手機工作室會顯示目前階段、已耗時及已完成的輸出數量。排隊時顯示前方任務數；生成期間依實際回報顯示模型準備、生成、作品儲存及資源釋放。計時每秒更新，結束後固定為最終耗時。

開始採樣後顯示「第幾步／總步數」、實際進度條及每步耗時。快速生成讀取 CLI 的採樣進度（不將模型載入進度當成步數）；ComfyUI 模式以本任務的 WebSocket 接收採樣事件，按 prompt ID 與採樣節點隔離。SVI 額外標示第幾段及高噪／低噪；換節點、細修輪次或下一個輸出時重新估速。

「本輪採樣預計剩餘」依實際完成步數的時間差更新，ComfyUI 排除首次模型載入等待，使用每步耗時的平滑平均；CLI 使用引擎回報的實測速度。此倒數不包含其他採樣輪次、解碼與存檔，採樣結束後顯示等待後續處理。步數停止回報、估時用完或 WebSocket 中斷時停止倒數並提示等待；WebSocket 自動重連，生成結果仍以原有 HTTP 工作流確認。

尚未收到採樣步數時，預計剩餘時間從本機最近五十筆同模式成功任務中，取最多五次相同生成設定、圖片數量及尾幀用法的耗時中位數，不計排隊時間。沒有符合紀錄時顯示「暫無法估算」。十五秒沒有收到主機回應時停止顯示倒數，提示等待更新與查看共用任務。整體時間仍會受首次載入、模型切換與內容影響。

新增 `websocket-client`（ComfyUI 官方範例使用的客戶端），隨 `tools/start-mobile.ps1` 安裝；不新增 `.env` 設定。採樣狀態只存於主機記憶體，不回傳原始引擎日誌、提示詞或預覽影像。

## 共用生成配方

桌面左側或手機設定區的「生成配方」可儲存目前設定；共用任務也提供「儲存為配方」。配方保留模式、提示詞、參數、精準模式，以及 SVI 的三段提示詞與已匯入 LoRA 名稱、權重。套用只填入表單，確認後再送出。

配方在主機 `.runtime/mobile/recipes.json` 保存，最多 100 份，桌面與已配對手機共用。暫存附件會過期，因此不保存附件或任意本機路徑，使用時重新選擇首幀、參考圖片及尾幀。原始模型或 LoRA 移除後仍須重新安裝；固定種子也不保證不同版本逐位元相同。

## 儲存用量與清理

管理區可手動掃描作品、上傳／生成暫存、各模型來源的大小及作品磁碟可用空間。分類內的硬連結不重複計算，分類間可能共用模型，因此不可直接加總為實體占用。

輸入保留天數（1～3650，預設 30），按「預覽清理清單」後會列出完整檔名、數量及大小，再按「確認刪除預覽中的作品」執行。清理僅涵蓋已結束任務記錄中的日期資料夾 PNG／MP4，以檔案最後修改時間判斷；不掃除模型、設定、上傳來源、其他檔案或 Google Drive 資料。沒有背景自動刪除。

預覽十分鐘後失效；執行時再次核對檔案身分、大小、修改時間與任務狀態，略過變動、進行中任務及符號連結／junction。成功刪除後同步更新任務的可下載檔案清單，保留提示詞與參數。刪除無法從本機復原，雲端已有副本不受影響。

所有 API 沿用工作室登入、Origin 與 CSRF 驗證；沒有新增 `.env` 參數。配方和清理操作會影響所有已配對設備的共用資料。
