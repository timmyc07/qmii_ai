# 跨裝置工作室

桌面與手機網頁透過同一個本機 FastAPI 服務提交任務，共用 SQLite 佇列、提示詞設定與作品庫。

支援四種圖片模式，以及 H3／SVI 影片模式：

- `quick`：文字生圖；有圖片時逐張修改。
- `reference`：需要 2～4 張參考圖片，融合生成一張圖片。
- `superduper`：文字生圖；上傳圖片時透過 Qwen 2.1 原生圖片條件逐張編輯，套用 `pussyV2` 與局部細修 LoRA。
- `nsfw_adv`：文字生圖；上傳圖片時透過 VAE 編碼逐張重繪，套用 NSFW Adv LoKr、Lightning 與 RES4LYF。
- `h3_image`：桌面與手機的 H3 圖片生影片，1～4 張首幀逐張生成，可選共用尾幀。
- `svi_image`：桌面的三段 SVI 高耗能影片。

模型健檢、生成配方及手動儲存清理見 [工作室管理](STUDIO_TOOLS.md)。

各模式都能上傳圖片並輸入提示詞。快速生成、SuperDuper 與 NSFW Adv 最多四張、逐張輸出；多圖參考以 2～4 張圖片融合生成一張。ComfyUI 模式會依設定寬高置中裁切輸入；NSFW Adv 的重繪強度預設 0.6，調低保留更多原圖，調高增加重新創作幅度。暫存的 ComfyUI 輸入複本在任務完成或失敗後刪除，原圖不受影響。

圖片模式驗證提示詞、圖片、寬高（256～2048 且為 32 的倍數）、步數、CFG、種子、負面提示詞與 LoRA／LoKr 強度。桌面與手機皆可提交 `h3_image` 影片工作，規則見 [H3 說明](H3.md)。所有任務一次只占用一個 GPU 鎖；輸出 PNG 會移除生成 metadata。

桌面、手機及各生成模式的成品統一保存在 `output/年-月-日/`，依主機本地日期分類；同一天直接放在同一資料夾，檔名為 `<任務編號>_<序號>.png` 或 `.mp4`。跨午夜批次的已完成成品保留原日期，後續成品歸入新日期。生成中的暫存檔放在 `.runtime/mobile/results/`。首次啟動新版時搬移既有任務成品並更新歷史下載路徑，已刪除的檔案不會復原；開發用基準與驗證資料不搬動。

右側創作設定列出每項參數的用途與調整影響。Euler 採樣器與 Turbo Sigma 排程固定；官方 Turbo 配方為 1024×1024、8 steps、CFG 1，留白即可沿用。

「精準模式」是桌面與手機共用開關，四種圖片生成模式皆適用。啟用時保留提示詞原文，僅附加從使用者模板整理的生成規範；關閉時不附加規範。不再翻譯、擴寫或呼叫 PE 重寫模型。

通用規範保護指定主體、數量、位置、風格、文字與物理一致性；有圖片時增加僅修改指定屬性、保留身份與未涉及區域、自然融合等要求；多圖參考模式另附來源角色與身份隔離規範。補充規範與原文衝突時以使用者明確要求為準。模板中的重寫格式、JSON、強制翻譯、句數與比例推斷不套用，也不改動所選生成參數。

`POST /api/jobs/{job_id}/cancel` 沿用登入、Origin 與 CSRF 驗證。排隊任務直接成為 `cancelled`；執行中先成為 `cancelling`，停止目前 CLI 子程序或以 ComfyUI 原生指定 prompt API 終止，在 GPU 鎖內等待確認停止。完成／失敗／已終止任務重複呼叫不改變結果；批次已完成輸出持續保留。桌面圖片與影片輸入區、手機圖片輸入區皆提供按鈕。服務無法確認模型停止時標示失敗並停止佇列，須確認模型停止後重啟工作室。
