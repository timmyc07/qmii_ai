# 跨裝置工作室

桌面與手機網頁透過同一個本機 FastAPI 服務提交 Qwen Image 2.1 Turbo 任務，共用 SQLite 佇列、提示詞設定與作品庫。

支援兩種模式：

- `quick`：文字生圖；有圖片時逐張修改。
- `reference`：需要 2～4 張參考圖片，融合生成一張圖片。

主機只接受這兩個工作流 ID，並驗證提示詞、圖片、寬高（256～2048 且為 32 的倍數）、步數、CFG、種子與負面提示詞。所有任務一次只占用一個 GPU 鎖；輸出 PNG 會移除生成 metadata。

右側創作設定列出每項參數的用途與調整影響。Euler 採樣器與 Turbo Sigma 排程固定；官方 Turbo 配方為 1024×1024、8 steps、CFG 1，留白即可沿用。

ComfyUI、LoRA、影片與其他底模不屬於目前工作室範圍。
