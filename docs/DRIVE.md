# Google Drive 自動上傳

左側「Google Drive 自動上傳」管理目標資料夾與開關。預設目標為使用者指定的 `Qmii_AI_output` 資料夾。桌面、手機與所有生成模式共用 `output/年-月-日/`；雲端同樣直接放在目標下的日期資料夾，例如 `Qmii_AI_output/2026-10-17/`。

## 首次連線

1. 依 [rclone 官方教學](https://rclone.org/drive/#making-your-own-client-id)，在 Google Cloud 建立專案、啟用 Google Drive API，設定 OAuth 同意畫面，建立「桌面應用程式」用戶端並下載 JSON。個人使用可依官方指引發布，保持測試模式的 refresh token 可能七天失效。
2. 在千迷AI管理區按「匯入 JSON 並登入」，選擇下載的檔案，在瀏覽器完成一次登入授權。程式會自動下載固定版本 rclone v1.75.2，並驗證官方 SHA256。
3. 保留「開啟自動上傳」，確認目標資料夾連結後儲存。Google 帳號需有該資料夾的新增權限。

資料夾分享連結本身不能匿名上傳；首次授權後不必每次登入。OAuth 用戶端資料與 refresh token 保存在 `.runtime/mobile/drive/rclone.conf`，不經手機 API 回傳、不提交 Git；原 JSON 不修改。開關與目標保存在本機管理設定，不使用 `.env`。

## 執行方式

工作室服務開啟後，背景上傳已完成的日期資料夾；新成品會喚醒上傳，並每 30 秒補查及重試。上傳使用 rclone `copy --checksum --immutable`：相同內容跳過，名稱相同但內容不同時拒絕覆蓋，不刪除本機或雲端檔案。生成與下載不等待雲端；關閉上傳或修改目標會中止目前傳輸，後續依新設定處理。服務停止時中止上傳，再啟動後補傳。

只上傳日期資料夾內的圖片與 MP4；設定、上傳暫存、模型、開發基準與驗證資料不納入。需要電腦持續開機、連網及工作室服務保持開啟。管理面板顯示目前狀態與本次服務啟動後的上次完成時間。
