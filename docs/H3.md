# H3 參數與身分一致性

在「圖片生影片」頁的右側設定欄調整，窄視窗可按上方「創作設定」。參數會隨任務記錄，按「儲存此模式設定」才會成為下次的預設。「還原配方」可恢復建議值。

底部可一次選取 1～4 張首幀，每張照片各自生成一支影片，套用同一提示詞與影片參數。在同一把 GPU 鎖內依序生成，每完成一支即回報結果並可播放、下載。輸出依序為任務目錄內的 `0.mp4`～`3.mp4`；若某支失敗即停止批次，保留先前完成的影片並標示失敗位置。固定種子逐張加一，到 `9007199254740991` 後回到 0；留白則每支隨機。

首幀清單使用請求的 `images`，自選尾幀使用獨立的 `last_image` 上傳 ID，因此可提交 4 張首幀加 1 張尾幀。自選尾幀模式必須提供有效尾幀，其他模式不可夾帶尾幀。

影片頁及影片任務詳情維持只有正向提示詞，不加入負面欄位。圖片模式及通用模板可分開填寫正向／負面內容；H3 套用模板時只取正向部分，不會傳送或併入負面詞。切回圖片模式會保留原先的負面內容。[H3 官方提示詞說明](https://github.com/Comfy-Org/docs/blob/main/tutorials/video/minimax/minimax-h3-prompt-guide.mdx)

## 可調參數

| 參數 | 範圍與作用 |
| --- | --- |
| 品質配方 | Turbo 4 步 768p／Turbo 8 步 544p／原版 20～60 步。切換會同時重設步數、採樣器、LoRA 權重與 shift。8 步使用本機已有的 v1.0 LoRA，與 768p 版為不同模型。 |
| 片長 | 1～15 秒，24 fps，向上對齊 `17k+5` 幀，面板顯示實際時長。低於約 5 秒屬較短片段，品質需自行比較。 |
| 寬高 | 256～1344、32 的倍數；短邊最多 768。768p 更耗記憶體。 |
| 種子 | 留白隨機；固定種子方便比較其他參數，不能當作身分鎖。 |
| 適配與縮放 | 置中裁切保留比例；拉伸保留完整內容但可能變形。Lanczos／Bicubic／Bilinear／Area／Nearest Exact。首尾幀使用相同適配規則。 |
| 原版步數 | 20～60；Turbo 固定配對 4 或 8 步，避免誤用蒸餾 LoRA。 |
| 採樣器 | Euler 為作者預設；Res Multistep 可供比較。Simple 排程固定。 |
| LoRA 權重 | 0～2，預設 1；只適用 Turbo。偏離訓練配方可能降低品質。原版不載入 Turbo LoRA。 |
| 影音 shift | 各 0.01～100。4 步 768p 預設 6／3，8 步 544p 與原版預設 12／3。修改會改變採樣時間分配，不代表身分強度。 |
| 聲音 | 可關閉音訊解碼與輸出；模型仍聯合生成影音。 |
| MP4 CRF | 0～51，預設 18；數值越低檔案越大。輸出固定 H.264、8-bit、sRGB。 |

H3 使用 CFG 蒸餾模型與 Basic Guider，面板不提供不會被此圖使用的負面提示詞與 CFG。去噪固定 1：首幀由原生條件提供，降低去噪並不等於圖片模式的保臉強度。24 fps 是模型時間基準，不能當作任意播放速度調整。

配方依據：[Turbo 作者模型規格](https://github.com/ModelTC/Minimax-H3-Turbo#1-model-specs)、[作者 ComfyUI 使用方式](https://github.com/ModelTC/Minimax-H3-Turbo/blob/main/COMFYUI_SETUP_AND_INFERENCE.md)。

## 可選一致性輔助

- **主體一致性描述**：在 `integrated_multimodal_description` 加入保留 `<Picture 1>` 主體特徵的文字。預設關閉，不能保證臉部不漂移。
- **以首幀作尾幀**：每支影片將各自的首幀接到 H3 原生 `last_frame`；適合返回起始姿勢，可能壓低動作幅度，不能保證形成無縫循環。
- **自選尾幀**：另選一張終點畫面，每支影片共用此圖並接到原生 `last_frame`，不佔首幀額度；程式會加入 `<Picture 2>` 的尾幀時間參照。只有首尾端點受此條件引導，不會鎖定中間每幀。儲存設定不儲存尾幀檔案，重新開啟後須再次選圖。

以上沿用官方首尾幀工作流與目前 FL2VA 模型，沒有額外的身分模型下載。使用清楚的首幀、避免長時間遮臉與快速轉身，是可供比較的實作建議，並非經過本機 A/B 評測的結論。[ComfyUI 原生 H3 說明](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-native)

## RefMod 身分參考

影片設定提供「啟用 RefMod 身分參考」，預設關閉，可隨影片參數儲存。啟用時每支影片從各自首幀建立參考，不會把批次中的其他人物混入同一支影片；仍維持原生首幀、選定尾幀、音訊與正向提示詞規則。關閉時不加入任何 RefMod 節點。

| 現有模型／模式 | RefMod |
| --- | --- |
| H3 FL2VA INT8 + Turbo 4 步 768p LoRA | 可選，已實際生成測試影片 |
| H3 FL2VA INT8 + Turbo 8 步 544p LoRA | 可選，已實際生成測試影片 |
| H3 FL2VA INT8 原版 20～60 步 | 可選，已用 20 步實際生成測試影片 |
| 快速生成／多圖參考：Qwen Image 2.1 Turbo GGUF | 不相容，介面停用並說明原因 |
| SuperDuper：Qwen Image 2.1 INT8 及其 LoRA | 不相容，介面停用並說明原因 |
| NSFW Adv：Qwen Image FP8、LoKr 與 Lightning | 不相容，介面停用並說明原因 |

RefMod 使用 H3 專用的 24-channel VAE latent 與 `minimax_refs` 條件，不能直接接到 Qwen。依已安裝的原生 H3 實作，額外參考條件可與 FL2VA 的 `minimax_keyframes` 並存；此版以 `Extract → Apply → BasicGuider` 串接，沒有替換成 Ref2VA 模型。這項相容性判斷已通過節點驗證與 GPU 執行；不代表 FL2VA 的身分效果等同專用 Ref2VA checkpoint。

目前採單張首幀完整編碼、短邊上限 512、最多 1024 tokens、固定 retention 1，不合併其他參考、不寫入額外 `.safetensors`。RefMod 是參考 latent，不是角色 LoRA；可能一起帶入服裝、背景或構圖，增加耗時與記憶體，或減少動作幅度。建議用同一圖片、提示詞與種子比較開關效果，不能保證臉部不漂移。

安裝使用固定版本 `517e8c419a8584fbf69fceb487bc39d83e6a6ec8`（0.2.6），下載驗證與操作見 [模型說明](MODELS.md)。本機已完成三配方 × 三尾幀模式的實際節點驗證，以及三配方各一支 256×256、請求 1 秒、無聲 GPU 測試，輸出皆可解碼為 39 幀（對齊後 1.625 秒）；尚未做身分品質 A/B 評測。

## 強制終止

送出後可按輸入區的「強制終止」。終止只針對該任務的 ComfyUI prompt，確認停止後才執行下一項；已完成影片仍可播放、下載，未完成項目不會繼續生成。若模型服務無法確認停止，任務會標示失敗、停止佇列並說明原因，須確認模型停止後重啟工作室。關閉視窗不等同終止任務。
