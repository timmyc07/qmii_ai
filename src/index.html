RefMod 僅支援 MiniMax H3，無法套用到 Qwen 圖片模型。

Qwen Image 2.1 生成設定。

生成模式

工作流

Qwen Image Turbo 文字生圖；有圖片時逐張修改。

生成參數

留白沿用所選工作流配方。參數會記錄在任務中，方便重現。

配方固定：Euler 採樣器、Turbo 8-step Sigma 排程。步數不是 8 時會改用模型的一般排程。

MiniMax H3 圖片生影片。請在下方上傳一張首幀，並描述畫面、動作與聲音。

提示詞格式說明

保留首幀參照 Header，以及 integrated_multimodal_description、overall_soundscape、non_diegetic_music 三個標籤；段落間空一行。時間碼須在設定片長內，首幀描述應與圖片一致。無配樂填 N/A。

影片設定

一致性輔助（可選）

每支影片以各自首幀建立 RefMod，加入 H3 參考條件。會增加耗時與記憶體用量，也可能帶入背景；不能保證身分不漂移。

在提示詞中要求保留首幀主體特徵；這是文字引導，不能保證臉部不漂移。

使用 H3 原生首尾幀條件。相同首尾幀適合回到起始姿勢，可能減少動作幅度；不會鎖定影片中間每一幀。自選尾幀在提示詞中以 <Picture 2> 參照。

RefMod 使用方式與限制

RefMod 是 H3 VAE 參考資料，不是角色 LoRA。此開關沿用目前 FL2VA 與所選 Turbo／原版配方，保留首尾幀及音訊規則，只加入額外影像參考。使用單張首幀的完整編碼，不混合批次中其他人物；關閉即恢復原工作流。

參考尺寸短邊上限 512、最多 1024 tokens，不儲存額外參考檔。先比較同一首幀、提示詞與種子下的開關效果；可能降低動作幅度或帶入場景細節。

進階生成與輸出參數

配方切換會重設下列採樣參數。Turbo 步數固定配對 LoRA；修改權重或 shift 可能降低品質，還原配方可復原。

CRF 越低檔案越大，18 為預設。關閉聲音只略過音訊解碼與輸出，模型仍聯合生成影音。

配方固定：24 fps、Simple 排程、完整去噪、CFG 蒸餾引導、H.264／8-bit／sRGB MP4。CFG、負面提示詞及重繪強度不適用此工作流。短邊最多 768、長邊最多 1344，寬高須為 32 倍數。

高耗能圖片轉影片模式

上傳一張首幀，依序填寫三段提示詞。後兩段承接前一段的動作，最後合併為一支無聲影片。

額外 LoRA

HIGH／LOW 各可選一個本機 LoRA，三段共用。SVI Pro 與 Lightning 已固定保留；不選擇就沿用原配方。

HIGH · 高噪支線未選擇額外 LoRA

權重 0 為停用；建議先用 0.3～0.5，再依作者說明調整。

任務結束，自動釋放

完成、失敗或強制終止後，都會清理模型與快取，確認生成程序退出後再執行下一項任務。

此模式會大量使用記憶體，首次載入需要較長時間。已完成的影片會保留，可播放與下載。

三段共用同一個種子；負面提示詞共用於三段，留白沿用作者配方。

額外 LoRA 怎麼選？

選擇作者明確標示 Wan 2.2 I2V A14B 相容的角色、風格或動作 LoRA。HIGH 檔只接高噪支線，LOW 檔只接低噪支線；單檔依作者說明使用，不直接複製到兩邊。

SVI Pro 與 Lightning 已隨配方載入。額外 LoRA 是疊加用途；Qwen、H3、SD、FLUX 及 Wan 5B／1.3B 的 LoRA 不適用。Wan 2.1 或 T2V 版本需作者另行確認 I2V 相容性。

三段維持同組 LoRA、權重與觸發詞。只選擇檔案不代表相容性已驗證，請核對模型作者的使用說明。
